# بلاغ الحملة القومية للتطعيم — بطعم MR (إدارة قويسنا الصحية)

موقع جاهز للرفع على **GitHub Pages**، أو التشغيل على سيرفر محلي.

---

## التشغيل على GitHub Pages (مفيش سيرفر)

1. حط ملف الشيت باسم **`baseline.xlsx`** في نفس المجلد اللي فيه `index.html`.
2. ارفع المجلد كله على الريبو.
3. Settings → Pages → Branch: `main` / root → Save.
4. افتح `https://<اسم-حسابك>.github.io/<اسم-الريبو>/`

اسم الشيت المفضّل: **`baseline.xlsx`**.

ولو سميته أي اسم تاني، الموقع بيدوّر عليه لوحده (عن طريق GitHub API) طالما الريبو عام
وملفه `.xlsx` أو `.xls` أو `.csv`. الأسماء الشائعة اللي بيجرّبها على طول:

```
baseline.xlsx · Baseline.xlsx · شيت.xlsx · بلاغ.xlsx · البلاغ اليومي للادارة.xlsx
```

**مش لاقي الشيت؟** افتح `check.html` — بتقولك بالظبط جرّب إيه ولاقى إيه.

عايز اسم مخصص؟ افتح `sheet-source.js` وعدّل:

```js
const SHEET_FILE = "اسم-الملف.xlsx";
```

### التحديث اليومي
بدّل `baseline.xlsx` بملف اليوم الجديد (Add file → Upload files → Commit).
كل الوحدات هتشوف التحديث فورًا (الصفحة بتنزّل الملف بـ cache-buster).

---

## التشغيل على سيرفر محلي (اختياري)

```bash
PORT=3000 ADMIN_KEY=كلمة_السر node server.js
```

- صفحة الإدارة: `http://<ip>:3000/admin.html` — رفع الشيت وبيتخزن في `data/`.
- السيرفر له الأولوية على ملف `baseline.xlsx` لو الاتنين موجودين.

---

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `unit.html` | صفحة الوحدة — إدخال البيانات وتنزيل PDF |
| `admin.html` | صفحة الإدارة — معاينة الشيت وجدول الوحدات |
| `sheet-source.js` | قراءة الشيت (CSV/Excel) من ملف الفولدر |
| `common.js` | أسماء الوحدات + طبقة البيانات (سيرفر/فولدر/كاش) |
| `pdf.js` | توليد البلاغ على النموذج الرسمي |
| `template-bg.js` | خلفيات صفحات النموذج بدقة 250dpi |
| `xlsx.full.min.js` | قراءة ملفات Excel في المتصفح |
| `server.js` | سيرفر اختياري بدون أي مكتبات خارجية |
| `baseline.xlsx` | **ملف الشيت اليومي — ده اللي بتستبدله كل يوم** |
